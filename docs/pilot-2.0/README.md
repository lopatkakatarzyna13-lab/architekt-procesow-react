# Scenariusze warsztatów do pilota Architekta Procesów 2.0

Te trzy fikcyjne rozmowy są materiałem do przyszłej oceny działania aplikacji. Nie zawierają danych rzeczywistych osób ani firm. Nie stanowią testu automatycznego ani dowodu, że funkcje AI lub BPMN są już wdrożone.

Każdy plik zawiera transkrypcję oraz osobno oczekiwane wyniki dla osoby oceniającej. Podczas późniejszych prób do modelu należy przekazywać wyłącznie treść sekcji „Transkrypcja”, bez wzorca oceny. Numeracja wypowiedzi pomaga wskazać źródło kroku. Oczekiwane wyniki nie przesądzają jedynego poprawnego układu graficznego mapy.

Ocena powinna uwzględniać: kolejność i połączenia, role, decyzje i wyjątki, zgodność ze źródłem oraz wskazanie brakujących informacji zamiast dopowiadania faktów. Wygenerowany wynik należy ocenić przez człowieka.
