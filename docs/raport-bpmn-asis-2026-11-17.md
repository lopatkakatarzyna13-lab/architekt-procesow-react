# BPMN AS-IS w raporcie PDF

Raport tworzy obraz SVG z tego samego modelu BPMN, którego używa podgląd i eksport. Do diagramu dodano opis decyzji, dodatkowych przejść, basenów, wiadomości i kolejności działań uczestnika zewnętrznego. Tekst pozostaje pomocny, gdy duży diagram po dopasowaniu do strony jest mały. Osobna mapa podstawowa AS-IS jest oznaczona jako uproszczona; mapa TO-BE nadal nie jest pełną mapą BPMN.

Jeśli model nie przejdzie walidacji lub nie uda się utworzyć obrazu, raport podaje powód i nie udaje, że zawiera diagram BPMN. Opisy połączeń nie są wykonywalnymi regułami. Kontrola XSD nie potwierdza poprawności biznesowej. W przypadku długich lub gęstych diagramów korzystanie z osobnego pliku BPMN może być wygodniejsze niż druk w jednej skali.
