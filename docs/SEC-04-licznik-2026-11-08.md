# SEC-04 — wykrywanie braku licznika

Punkt wyjścia: 90be49c437dc15afd8fb8537a82b698a23495ced. Status SEC-04: OTWARTY.

Dodano znacznik inicjalizacji obok lokalnego pliku licznika. Po pierwszym udanym zapisie brak samego pliku licznika blokuje analizy także po restarcie. Istniejący poprawny licznik jest zachowany; znacznik powstaje przy najbliższej dopuszczonej próbie. Błąd zapisu skutkuje blokadą. Gdy licznik jest niedostępny, nie usuwać automatycznie plików ani nie resetować limitu; ustalić przyczynę i odtworzyć stan z zaufanej kopii lub odczekać i przeprowadzić świadome uruchomienie zgodnie z przyszłą procedurą.

Ograniczenia: jednoczesne usunięcie obu plików jest nierozróżnialne od pierwszego uruchomienia; znacznik nie chroni przed edycją, uprawnionym lokalnym użytkownikiem lub wieloma procesami. Istniejący licznik na wyczerpanym limicie otrzyma znacznik dopiero po pierwszym dozwolonym zapisie. Kontrola Origin nie jest uwierzytelnieniem, a lokalny licznik nie jest limitem rozliczeń dostawcy. Niezależne limity kosztów oraz pełny model dostępu nadal wymagają weryfikacji. W razie uruchomienia publicznego API wymagane są osobne mechanizmy uwierzytelnienia, autoryzacji i kontroli kosztów.

Lokalne testy zmiany: 176/176 Vitest, 4/4 testy HTTP smoke, ESLint i build — sukces. Testy wykorzystują dane fikcyjne i dostawcę symulowanego, bez płatnego API. Weryfikacja w prawdziwym Chromium dla niniejszej zmiany następuje w GitHub Actions; nie została przeprowadzona lokalnie.
